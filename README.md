# Tuckleaf

Support and privacy pages for the Tuckleaf iPhone app, and the app's dictionary data under CC BY-SA 4.0
(see Releases).

The public website, with the current support and privacy pages, is https://tuckleaf.com. These two pages stay
because the App Store, Google Play and the apps link to them, but they carry `noindex` so search engines show
tuckleaf.com instead. Keep the noindex unless tuckleaf.com goes away. Why: `docs/knowledge/web-seo-review.md` in
the tuckleaf-ios repo (2026-11-14).
